# Netflix_clone
A simple, responsive Netflix homepage clone built using only HTML, CSS, and JavaScript. This project recreates the look and feel of Netflix’s landing page and UI components, such as the navigation bar, banner, and movie cards.
Features
🔻 Netflix-style user interface

🎞️ Hero section with background image and content

📂 Horizontal scrolling movie rows

🔁 Hover animations and transitions

✅ Fully responsive design

🌓 Dark-themed layout

🧭 Navigation bar with logo and buttons
Technologies Used
HTML5 – for structuring the content

CSS3 – for styling, layout (Flexbox, Grid), transitions

JavaScript (ES6) – for interactivity and dynamic elements
